# 환자 화면 ASCII 점검 리포트 (Autoresearch)

## 목표
- 4개 핵심 화면 × 3개 핵심 기준(정보구조/행동유도/정서톤) + 채팅 품질/접근성/빈상태 확장 점검

## 핵심 화면 ASCII

### 1) 홈 (PatientHomeScreen)
```
┌──────────────────────────────┐
│ 3월 30일                     │
│ 우리 아기                    │
├──────────────────────────────┤
│ [말풍선: 아기 메시지]         │
│            (아기 이미지)      │
├──────────────────────────────┤
│ [주차/만나기까지 카드]        │
│ [오늘의 한마디 카드]          │
└──────────────────────────────┘
```
호출 흐름: homePort.getHomeView → buildPatientHomeViewModel

### 2) 오늘,우리 (PatientTodayScreen)
```
┌──────────────────────────────┐
│ 탭: 아기와엄마 | 체크 | 대화   │
├──────────────────────────────┤
│ [정보 카드 2개]               │
│ or [체크리스트]               │
│ or [대화 리스트 + 입력창]     │
└──────────────────────────────┘
```
호출 흐름: todayPort.getTodayView / chatPort.listRecentChats / chatPort.sendMessage

### 3) 마이페이지 (PatientProfileScreen)
```
┌──────────────────────────────┐
│ [아기 카드            ⚙]      │
├──────────────────────────────┤
│ [활동 캘린더]                 │
│ [외부 설문]                   │
│ [계정/로그아웃]               │
└──────────────────────────────┘
```
호출 흐름: profilePort.getProfile / homePort.getHomeView / todayPort.getTodayView / homePort.getRecordDay

### 4) 기록 상세 (PatientRecordDayScreen/모달)
```
┌──────────────────────────────┐
│ 날짜                          │
│ 상태 탭(정보/체크/대화)       │
├──────────────────────────────┤
│ 선택 섹션 내용                │
└──────────────────────────────┘
```
호출 흐름: homePort.getRecordDay
