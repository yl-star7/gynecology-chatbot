# 화면 기능 표

최종 업데이트: 2026-03-23

이 문서는 현재 배포 및 코드 기준으로 유저 화면과 관리자 화면에서
무엇을 할 수 있는지, 그리고 각 화면에서 어디로 이동하는지를 표로 정리한 문서다.

## 유저 화면

| 화면 | 경로 | 할 수 있는 것 | 이동 경로 |
| --- | --- | --- | --- |
| 홈 | `/` | 현재 주차와 임신 경과 확인, 임신수첩 진입, 임신 지식 진입, 최근 채팅 이어가기, 프로필 진입, 새 상담 시작 | `/notebook`, `/knowledge`, `/chat/[sessionId]`, `/chat/new`, `/profile` |
| 로그인 | `/auth/login` | 전화번호 입력, 인증번호 요청, 인증번호 입력 후 로그인, 테마 선택 | 로그인 성공 시 `/`, 온보딩 미완 시 `/onboarding` |
| 온보딩 | `/onboarding` | 이름, 예정 출산일, 태명, 병원, 알림 시간, 테마, 상담 톤 입력 | 완료 후 `/` |
| 프로필 | `/profile` | 이름, 태명, 예정 출산일, 병원, 채팅 톤, 알림 시간, 테마 변경, 로그아웃 | 뒤로 버튼으로 `/`, FAB로 `/chat/new` |
| 임신 지식 목록 | `/knowledge` | 지식 문서 목록 확인, 상세 진입 | 상세 콘텐츠, FAB로 `/chat/new` |
| 임신수첩 | `/notebook` | 저장 기록, 체크리스트, 관련 내용 확인 | 상세 콘텐츠, FAB로 `/chat/new` |
| 링크형 참고 콘텐츠 | `/link/[target]` | 챗봇이 연결한 참고 콘텐츠 읽기 | 뒤로 버튼으로 `/`, FAB로 `/chat/new` |
| 채팅 상세 | `/chat/[sessionId]` | 이전 대화 확인, 새 메시지 전송, 첨부/내부 링크 확인 | 링크형 콘텐츠, 프로필, 다른 세션 |
| 날짜별 기록 | `/records/[isoDate]` | 날짜별 기록, 감정, 연결 채팅 확인 | 연결 채팅, FAB로 `/chat/new` |

## 관리자 화면

| 화면 | 경로 | 할 수 있는 것 | 이동 경로 |
| --- | --- | --- | --- |
| 관리자 로그인 | `/admin/login` | 전화번호와 비밀번호로 관리자 로그인 | 성공 시 `/admin` -> `/admin/operations` |
| 운영 상태 | `/admin/operations` | 푸시 알림 발송, 안부 메시지 트리거, 벡터 검색 설정 저장, 알림 스케줄 저장, FAB 마스코트 업로드/저장, 세션 종료 | `계정`, `콘텐츠`, `모니터링` |
| 계정 | `/admin/accounts` | 사용자 목록 확인, 전화번호 변경, 세션 초기화, 허용 전화번호 추가/수정/삭제 | `운영 상태`, `콘텐츠`, `모니터링`, 세션 종료 |
| 모니터링 | `/admin/monitoring` | 실시간 사용자 이벤트 확인, 액션 타입 필터, 사용자별 감사 로그 확인, 채팅 세션 감사 확인 | `운영 상태`, `계정`, `콘텐츠`, 세션 종료 |
| 문서 | `/admin/content/documents` | 문서 테이블 확인, 검색/상태 필터, 행 클릭으로 우측 편집 패널 열기, 제목/카테고리/주차/본문 수정, 새 문서 생성, 문서 반영, 문서 삭제 | 다른 콘텐츠 탭, 세션 종료 |
| 정적 문헌 | `/admin/content/static` | 문헌 테이블 확인, 검색/상태 필터, 행 클릭으로 우측 편집 패널 열기, 슬러그/섹션/제목/상태/본문 수정, 정적 문헌 생성/수정/삭제 | 다른 콘텐츠 탭, 세션 종료 |
| 주차 데이터 | `/admin/content/weeks` | 주차 테이블 확인, 검색/상태 필터, 행 클릭으로 넓은 우측 편집 패널 열기, 주차 제목/상태 수정, 아기 요약/산모 요약 수정, Day별 본문 수정, 체크리스트 수정, 질문 수정, 이미지 매핑 수정, 이미지 업로드, 주차 저장 | 다른 콘텐츠 탭, 세션 종료 |
| 응답 정책 | `/admin/content/policies` | 정책 테이블 확인, 검색/상태 필터, 행 클릭으로 우측 편집 패널 열기, 정책 이름/트리거/검색 범위/모델/상태 수정, 정책 저장 | 다른 콘텐츠 탭, 세션 종료 |

## 관리자 콘텐츠 하위 분기

| 섹션 | 경로 | 기능 |
| --- | --- | --- |
| 문서 | `/admin/content/documents` | 임베딩 기반 문서 업로드/반영/삭제 |
| 정적 문헌 | `/admin/content/static` | 고정 문헌 CRUD |
| 주차 데이터 | `/admin/content/weeks` | 주차별 본문, 질문, 체크리스트, 이미지 매핑 및 업로드 |
| 응답 정책 | `/admin/content/policies` | 응답 정책 CRUD |

## 공통 이동 규칙

| 구분 | 규칙 |
| --- | --- |
| 유저 화면 | 홈 중심 구조이며 대부분 화면에서 FAB로 새 상담 시작 가능 |
| 유저 상세 화면 | 프로필, 링크형 콘텐츠, 콘텐츠 상세는 뒤로 버튼으로 홈 복귀 가능 |
| 관리자 화면 | `/admin/operations`가 기본 진입점이며 좌측 사이드바로 `계정`, `콘텐츠`, `모니터링` 이동 |
| 관리자 콘텐츠 | `문서`, `정적 문헌`, `주차 데이터`, `응답 정책`으로 하위 분기 |

## 현재 확인된 상태

| 범위 | 상태 |
| --- | --- |
| 유저 주요 화면 렌더 | 확인됨 |
| 관리자 주요 화면 렌더 | 확인됨 |
| 관리자 설정 저장 일부 | 확인됨 |
| 관리자 콘텐츠 읽기 화면 | 테이블 선진입 + 오버레이 편집 패턴으로 확인됨 |
| 관리자 문서/이미지 업로드 경로 | 로컬 검증 완료, 배포 반영 후 추가 확인 필요 |
