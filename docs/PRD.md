# [PRD] 부인과 전용 AI 챗봇 서비스 (임산부 맞춤 케어)

> **상태**: 구현 완료 (V1.0)  
> **핵심 가치**: "전문적인 의료 지식을 바탕으로 가장 가깝게 챙겨주는 AI 동반자"

---

## 1. 서비스 개요
임산부 및 부인과 환자를 위해 전문 의료 문서(RAG)를 기반으로 답변하고, 사용자의 임신 주차에 맞춰 선제적으로 건강을 체크하는 하이브리드(Web+Mobile) 서비스입니다.

---

## 2. 기능별 상세 사양 (Feature by Feature)

### [F1] 카카오 단일 인증 (Kakao-First Auth)
*   **요구사항**: 이메일/비밀번호 가입 절차를 완전히 제거하고 카카오 로그인으로 통합.
*   **UX 고려사항**: 
    *   **접점 최소화**: "가입"과 "로그인" 버튼을 구분하지 않고 "카카오로 3초 만에 시작하기" 단일 버튼으로 처리.
    *   **데이터 연동**: 카카오 프로필에서 이름, 이메일 정보를 자동으로 획득하여 온보딩 허들을 낮춤.
*   **보안**: Supabase Auth와 카카오 OAuth를 연동하여 안전한 세션 관리.

### [F2] 초정밀 온보딩 (Personalized Onboarding)
*   **요구사항**: 임신 상태, 예정일, 과거 병력, 알러지 정보를 수집.
*   **UX 고려사항**:
    *   **마법사 UI**: 한 번에 한 가지 질문만 던져 피로도를 낮춤.
    *   **주차 자동 계산**: 출산 예정일 입력 시 현재 주차를 자동 계산하여 개인화 엔진에 반영.
    *   **페르소나 매칭**: 사용자의 성향(T형/F형)에 따라 '따뜻한 친구' 또는 '전문 상담사' 페르소나를 추천/선택 유도.

### [F3] RAG 기반 전문 상담 (Medical AI Chat)
*   **요구사항**: 업로드된 전문 의학 문서(DOCX)에서 정답을 찾아 답변하고 출처를 밝힘.
*   **UX 고려사항**:
    *   **근거 제시**: 답변 하단에 "참조한 의학 정보" 리스트를 노출하여 신뢰성 확보.
    *   **이미지 생성(Imagen)**: "내 아이의 크기는 어느 정도야?" 같은 질문 시 과일/물건 등으로 시각화하여 감성적 만족감 제공.
    *   **스트리밍(SSE)**: AI가 생각하는 시간을 줄여주기 위해 글자가 타이핑되듯 노출.

### [F4] 선제적 케어 매니징 (Proactive Push & Chat)
*   **요구사항**: 사용자가 먼저 묻기 전에 주차별 필수 체크리스트를 시스템이 먼저 제안.
*   **UX 고려사항**:
    *   **맥락 있는 알림**: "12주차네요! 오늘 정기 검진 잊지 않으셨죠?"와 같이 상황에 맞는 알림 전송.
    *   **알림-채팅 연결**: 푸시 클릭 시 해당 주제에 대한 대화가 즉시 시작되는 전문 채팅창으로 이동.
*   **기술**: `pg_cron` 스케줄러를 통한 자동화.

### [F5] 동적 정기 설문 (Strategic Surveys)
*   **요구사항**: 주차별로 증상 변화를 체크하기 위한 동적 폼(Google Forms 스타일) 제공.
*   **UX 고려사항**:
    *   **채팅 내 삽입**: 별도 페이지 이동 없이 채팅창 내에서 바로 설문 응답 가능.
    *   **데이터 시각화**: 응답 결과를 바탕으로 "정상 범위입니다" 또는 "전문의 상담이 필요합니다" 피드백 제공.

### [F6] 지식 공유 및 보관 (Knowledge Sharing)
*   **요구사항**: 도움이 된 AI의 조언을 영구 보관하거나 공유 가능하게 함.
*   **UX 고려사항**:
    *   **토큰 기반 공유**: 개인 정보는 제외하고 질문/답변 내용만 공개 페이지로 생성.
    *   **메모/태그**: 사용자가 나중에 찾기 쉽게 개인적인 메모를 추가 가능.

## 3. 사용자 여정 (UX Journey)

1.  **진입**: 랜딩 페이지에서 카카오 로그인 버튼 터치 (회원가입/로그인 동시 처리).
2.  **온보딩**: 3단계에 걸쳐 임신 정보 입력 후 맞춤형 페르소나 설정.
3.  **메인**: 대시보드에서 현재 내 아이의 성장 상태 확인 및 AI와 대화.
4.  **일상**: 오전 10시, 주차별 건강 팁 푸시 알림 수신 -> 탭하여 상세 가이드 확인.
5.  **위기**: "배가 아파요" 입력 -> RAG를 통한 긴급도 분석 -> "병원 내원 필요" 가이드 및 가까운 병원 안내.
6.  **마무리**: 유용한 정보는 '저장'하여 모아보고 배우자와 '공유'.

---

## 4. 기술 아키텍처 (High-Level)

- **Frontend**: Next.js 15 (Turborepo) - 웹/모바일 플랫폼 통합 관리
- **Mobile**: Expo (React Native) - 네이티브 푸시 및 하이브리드 앱
- **Backend**: Supabase (PostgreSQL + pgvector) - 벡터 검색 및 실시간 데이터
- **AI Brain**: Gemini 2.0 Flash + LangChain - 지능형 엔진
- **Automation**: pg_cron + Edge Functions - 선제적 시스템
