Capability Matrix

화면 기능 표

현재 코드와 배포 기준으로 유저 화면과 관리자 화면에서 할 수 있는 일, 그리고 각 화면이 어디로 이동하는지를 표 중심으로 정리한 문서입니다.

최종 업데이트: 2026-03-23

유저 화면

화면 경로 할 수 있는 것 이동 경로
홈 `/` 현재 주차와 임신 경과 확인, 임신수첩 진입, 임신 지식 진입, 최근 채팅 이어가기, 프로필 진입, 새 상담 시작 `/notebook`, `/knowledge`, `/chat/[sessionId]`, `/chat/new`, `/profile`
로그인 `/auth/login` 전화번호 입력, 인증번호 요청, 인증번호 입력 후 로그인, 테마 선택 로그인 성공 시 `/`, 온보딩 미완 시 `/onboarding`
온보딩 `/onboarding` 이름, 예정 출산일, 태명, 병원, 알림 시간, 테마, 상담 톤 입력 완료 후 `/`
프로필 `/profile` 이름, 태명, 예정 출산일, 병원, 채팅 톤, 알림 시간, 테마 변경, 로그아웃 뒤로 버튼으로 `/`, FAB로 `/chat/new`
임신 지식 목록 `/knowledge` 지식 문서 목록 확인, 상세 진입 상세 콘텐츠, FAB로 `/chat/new`
임신수첩 `/notebook` 저장 기록, 체크리스트, 관련 내용 확인 상세 콘텐츠, FAB로 `/chat/new`
링크형 참고 콘텐츠 `/link/[target]` 챗봇이 연결한 참고 콘텐츠 읽기 뒤로 버튼으로 `/`, FAB로 `/chat/new`
채팅 상세 `/chat/[sessionId]` 이전 대화 확인, 새 메시지 전송, 첨부/내부 링크 확인 링크형 콘텐츠, 프로필, 다른 세션
날짜별 기록 `/records/[isoDate]` 날짜별 기록, 감정, 연결 채팅 확인 연결 채팅, FAB로 `/chat/new`

관리자 화면

화면 경로 할 수 있는 것 이동 경로
관리자 로그인 `/admin/login` 전화번호와 비밀번호로 관리자 로그인 성공 시 `/admin` -> `/admin/operations`
운영 상태 `/admin/operations` 푸시 알림 발송, 안부 메시지 트리거, 벡터 검색 설정 저장, 알림 스케줄 저장, FAB 마스코트 업로드/저장 `계정`, `콘텐츠`, `모니터링`
계정 `/admin/accounts` 사용자 목록 확인, 전화번호 변경, 세션 초기화, 허용 전화번호 추가/수정/삭제 `운영 상태`, `콘텐츠`, `모니터링`, 세션 종료
모니터링 `/admin/monitoring` 실시간 사용자 이벤트 확인, 액션 타입 필터, 사용자별 감사 로그 확인, 채팅 세션 감사 확인 `운영 상태`, `계정`, `콘텐츠`, 세션 종료
문서 `/admin/content/documents` RAG 문서 목록 확인, 제목/카테고리/주차/본문 입력, 새 문서 생성, 문서 반영, 문서 삭제 다른 콘텐츠 탭, 세션 종료
정적 문헌 `/admin/content/static` 슬러그/섹션/제목/상태/본문 입력, 정적 문헌 생성/수정/삭제 다른 콘텐츠 탭, 세션 종료
주차 데이터 `/admin/content/weeks` 주차 목록 확인, Day별 본문, 체크리스트, 질문, 이미지 매핑 수정, 이미지 업로드, 주차 저장 다른 콘텐츠 탭, 세션 종료
응답 정책 `/admin/content/policies` 정책 목록 확인, 정책 이름/트리거/검색 범위/모델/상태 수정, 정책 저장 다른 콘텐츠 탭, 세션 종료

핵심 이동 관계

기준 화면 이동 가능 대상 상태 설명
유저 홈 임신수첩 가능 홈 카드에서 `임신수첩`으로 이동합니다.
유저 홈 임신 지식 가능 홈 카드에서 `임신 지식`으로 이동합니다.
유저 홈 최근 채팅 상세 가능 최근 채팅 목록에서 기존 세션 상세로 들어갑니다.
유저 홈 새 채팅 가능 홈의 FAB 또는 `새 상담` 진입으로 새 채팅을 시작합니다.
유저 홈 프로필 가능 우상단 프로필 진입 버튼으로 설정 화면에 들어갑니다.
유저 홈 기록 상세 가능 기록 달력/기록 흐름을 통해 날짜별 상세로 진입합니다.
유저 프로필 홈 가능 상단 뒤로 버튼으로 홈으로 돌아갑니다.
유저 프로필 새 채팅 가능 FAB로 새 상담을 바로 시작할 수 있습니다.
유저 콘텐츠/링크 상세 홈 가능 상단 뒤로 버튼 또는 홈 버튼으로 홈으로 복귀합니다.
유저 콘텐츠/링크 상세 새 채팅 가능 FAB로 바로 상담 흐름으로 이어집니다.
관리자 운영 상태 계정 가능 좌측 사이드바 `계정` 탭으로 이동합니다.
관리자 운영 상태 콘텐츠 가능 사이드바에서 `문서`, `정적 문헌`, `주차 데이터`, `응답 정책`으로 이동합니다.
관리자 운영 상태 모니터링 가능 실시간 사용자 이벤트/감사 로그 화면으로 이동합니다.
관리자 콘텐츠 문서 ↔ 정적 문헌 ↔ 주차 데이터 ↔ 응답 정책 가능 콘텐츠 하위 탭 사이를 좌측 탐색으로 오갈 수 있습니다.
