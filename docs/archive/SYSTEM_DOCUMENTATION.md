## 🎯 시스템 개요

### 무엇인가요?
임신부와 여성들을 위한 AI 상담 서비스입니다. 부인과 전문의 수준의 조언을 24시간 언제든지 받을 수 있습니다.

### 핵심 기능
- 💬 **AI 채팅**: 부인과 전문 지식을 바탕으로 한 실시간 상담
- 📊 **건강 기록**: 체중, 증상, 약물 복용 등 개인 건강 데이터 관리
- 📚 **의료 정보**: 임신 주차별 맞춤 정보 제공
- 🏥 **병원 예약**: 검진 일정 관리 및 알림
- 🚨 **응급 상황**: 위험 증상 감지 시 즉시 병원 안내

## 🤖 AI 대화 처리 과정

### 사용자가 질문했을 때 일어나는 일들

```
👩 "임신 중 엽산 언제까지 먹어야 하나요?"
                    ↓
        🔍 1단계: 질문 분석
        • 키워드 추출: 임신, 엽산, 기간
        • 분야 분류: 영양/보충제
        • 긴급도 판단: 일반 (0점)
                    ↓
        📚 2단계: 관련 의료 지식 검색
        • 임신 영양 가이드라인
        • 엽산 복용 권장사항
        • 주차별 영양 정보
                    ↓
        🧠 3단계: AI가 답변 생성
        • 검색된 의료 지식 + 사용자 질문
        • 부인과 전문의 톤으로 작성
        • 안전하고 정확한 정보 제공
                    ↓
        💾 4단계: 모든 내용 저장
        • 질문과 답변 대화 기록에 저장
        • AI 처리 정보 (모델명, 토큰 수)
        • 의료 키워드 및 출처 표시
                    ↓
        📱 5단계: 사용자에게 표시
        🤖 "임신 중 엽산은 임신 전부터 
           출산 후 수유기까지 지속 복용을
           권장합니다. 하루 400-800mcg..."
```

### 응급 상황 감지 시스템

```
👩 "갑자기 심한 하복부 통증과 출혈이..."
                    ↓
        🚨 위험 키워드 감지!
        • "심한 통증", "출혈" 
        • 긴급도: 2 (최고 위험)
                    ↓
        📢 즉시 경고 메시지 표시
        "⚠️ 응급 상황으로 판단됩니다
         즉시 가까운 병원 응급실로!"
                    ↓
        📞 응급 연락처 자동 표시
        • 119 응급실
        • 산부인과 응급실 리스트
```

## ❓ 자주 묻는 질문

**Q: 내 개인정보가 안전한가요?**
A: 네, 의료 데이터 보호 최고 수준을 적용합니다. 본인 외에는 누구도 접근할 수 없으며, 암호화하여 안전하게 보관됩니다.

**Q: AI 조언을 100% 믿어도 되나요?**
A: AI는 참고용 정보를 제공합니다. 중요한 결정은 반드시 담당 의료진과 상의하세요.

**Q: 응급상황 시 어떻게 대처하나요?**
A: 위험 키워드 감지 시 즉시 응급실 방문을 안내하고, 응급 연락처를 자동으로 표시합니다.

**Q: 데이터는 언제까지 보관되나요?**
A: 탈퇴 시 개인정보는 즉시 삭제되며, 의료 상담 기록은 법정 보관 기간(3년) 후 자동 삭제됩니다.
