기존 뷰에서 변경점

이미 있는 화면에 진입점과 운영 상태를 덧붙입니다.

  • M-01~03마이페이지에 `임신백과` 섹션과 두 개의 진입 항목을 추가합니다.
  • 탭하단 탭은 `홈 / 오늘,우리 / 마이페이지` 3개를 유지합니다.
  • A-01~05기존 관리자 주차 목록에 완료, 검수, 누락 상태를 더 명확히 표시합니다.
  • A-06~09기존 주차 편집 흐름에 원문/사용자 노출본 비교와 검수 체크를 추가합니다.

신규 뷰

마이페이지 진입 후 새로 열리는 사전형 화면입니다.

  • M-04~07현재 주차의 임신백과 상세 화면을 새로 제공합니다.
  • M-08다른 주차를 선택하고 준비 중 주차를 확인하는 화면을 제공합니다.
  • A-08~09Paraphrase 검수 패널을 운영자용 신규 작업 표면으로 둡니다.
  • A-10사용자 앱 미리보기 패널을 추가합니다.
