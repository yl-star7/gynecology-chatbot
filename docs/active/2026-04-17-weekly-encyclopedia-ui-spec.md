# 주차별 임신백과 UI 명세

- 작성일: 2026-04-17
- 상태: Draft v1
- 대상: 모바일 앱, 관리자 웹
- 기준 PRD: `docs/active/2026-04-17-weekly-encyclopedia-prd.md`

## 1. UI 방향

주차별 임신백과 UI는 검색형 지식창이 아니라 사전형 콘텐츠 표면이다.

앱에서는 산모가 현재 주차 정보를 차분히 읽고, 다른 주차로 이동해 볼 수 있어야 한다. 관리자 웹에서는 운영자가 주차별 완성도와 paraphrase 상태를 빠르게 확인하고 수정할 수 있어야 한다.

## 2. 공통 원칙

### 2.1 제품 원칙

- 주차가 첫 번째 탐색 단위다.
- 카테고리는 두 번째 탐색 단위다.
- 검색창은 MVP에서 제공하지 않는다.
- 사용자 앱에는 paraphrase 완료 콘텐츠만 노출한다.
- 관리자 웹에서만 원문을 확인할 수 있다.
- 채팅 CTA는 MVP에서 제공하지 않는다.

### 2.2 문구 원칙

앱 문구:

- 산모 대상 문구는 `-어요/-해요` 체를 사용한다.
- 개발자 용어를 쓰지 않는다.
- 원문, paraphrase, RAG 같은 운영 용어를 사용자에게 노출하지 않는다.
- 준비 중 상태도 차분하게 안내한다.

관리자 문구:

- 운영자 대상 문구는 `-습니다` 체를 허용한다.
- 상태, 누락, 검수, 발행 같은 운영 용어를 명확하게 사용한다.

### 2.3 모바일 디자인 시스템 적용

`apps/mobile/` 구현 시 기존 디자인 시스템을 따른다.

- spacing은 `space` 토큰 사용
- radius는 `radii` 토큰 사용
- typography는 `typo` 토큰 사용
- color는 `palette` 또는 `patientSurfacePalette` 사용
- 카드 그림자는 `shadows.card` 사용
- 카드에는 `borderWidth` 사용 금지
- 터치 요소는 `components/ui/Pressable` 우선 사용
- 버튼은 `components/ui/Button` 우선 사용
- ScrollView는 `showsVerticalScrollIndicator={false}` 기본 적용
- 목록/홈 성격 화면은 `RefreshControl` 포함

```text
 앱
  + 홈
  + 오늘,우리
  + 마이페이지
     + 임신백과
        + 이번 주 백과
        + 주차 선택
        + 주차 상세
           + 주차 요약
           + 태아 발달
           + 엄마 몸 변화
           + 생활 가이드
           + 주의할 점
           + 자주 궁금한 점
```

기존 라우트 기준:

- 사용자 진입: 맨 오른쪽 `마이페이지` 탭의 `임신백과` 섹션
- `임신백과`는 별도 하단 탭으로 노출하지 않는다.
- 내부 구현은 기존 `PatientContentScreen(section="knowledge")` 또는 지식 화면 코드를 재사용할 수 있으나, 사용자-facing IA는 프로필 하위 섹션으로 본다.

## 5. 사용자 앱 화면 명세

### 5.1 마이페이지 임신백과 섹션

목적:

마이페이지 안에서 주차별 임신백과로 들어가는 단일 섹션을 제공한다.

와이어프레임:

```text
+--------------------------------------+
| <            마이페이지               |
+--------------------------------------+
|                                      |
|  내 정보                              |
|  지유님과 별이                        |
|  현재 18주차예요.                     |
|                                      |
|  임신백과                             |
|  [ 18  이번 주 백과 보기          > ] |
|  [ 주  다른 주차 찾아보기         > ] |
|                                      |
|  설정                                 |
|  [ 이름과 태명                    > ] |
|  [ 알림 시간                      > ] |
|                                      |
+--------------------------------------+
| 홈             오늘,우리      마이페이지 |
+--------------------------------------+
```

진입 규칙:

- 하단 탭에는 `임신백과`를 추가하지 않는다.
- 맨 오른쪽 `마이페이지` 탭을 통해서만 진입한다.
- 섹션 제목은 `임신백과`로 표시한다.
- 첫 항목은 현재 주차가 있으면 `이번 주 백과 보기`로 표시한다.
- 두 번째 항목은 `다른 주차 찾아보기`로 표시한다.

### 5.2 임신백과 홈

목적:

현재 산모 주차 기준으로 이번 주 임신백과를 보여주고, 다른 주차로 이동할 수 있게 한다.

상태:

- 현재 주차 있음
- 현재 주차 없음
- 현재 주차 콘텐츠 준비 중
- 로딩
- 오류

와이어프레임:

```text
+--------------------------------------+
| <            임신백과                 |
+--------------------------------------+
|                                      |
|  이번 주 백과                         |
|  18주차                              |
|  아기는 고구마만큼 자라고 있어요       |
|                                      |
|  [ 다른 주차 보기 ]                   |
|                                      |
| +----------------------------------+ |
| | 18주차 한눈에 보기                 | |
| | 이번 주에는 아기의 움직임과         | |
| | 엄마의 몸 변화를 함께 살펴봐요.     | |
| +----------------------------------+ |
|                                      |
|  [ 태아 발달 ]                       |
|  아기의 성장과 움직임을 확인해요       |
|                                      |
|  [ 엄마 몸 변화 ]                    |
|  몸에서 느껴지는 변화를 차분히 봐요    |
|                                      |
|  [ 생활 가이드 ]                     |
|  이번 주에 챙기면 좋은 일을 봐요       |
|                                      |
+--------------------------------------+
| 홈             오늘,우리      마이페이지 |
+--------------------------------------+
```

컴포넌트:

- `PatientShell`
- `ScrollView`
- `Card`
- `Button`
- `Pressable`
- `RefreshControl`

주요 인터랙션:

- `다른 주차 보기` 버튼: 주차 선택 바텀시트 열기
- 카테고리 카드 탭: 같은 화면 내 해당 섹션으로 스크롤하거나 상세 영역 확장
- Pull to refresh: 최신 콘텐츠 다시 조회

권장 문구:

- Eyebrow: `이번 주 백과`
- 제목: `{weekNumber}주차`
- 설명: `이번 주 아기와 엄마의 변화를 차분히 살펴봐요.`
- 주차 미설정: `임신 주차를 알려주시면 이번 주 백과를 먼저 보여드릴게요.`

### 5.3 주차 상세

목적:

선택한 주차의 사전 콘텐츠를 카테고리별로 읽게 한다.

와이어프레임:

```text
+--------------------------------------+
| <            18주차                   |
+--------------------------------------+
|                                      |
| [18주] [19주] [20주] [21주]          |
|                                      |
| +----------------------------------+ |
| | 18주차 한눈에 보기                 | |
| | 아기의 감각과 움직임이 조금씩       | |
| | 더 뚜렷해지는 시기예요.             | |
| +----------------------------------+ |
|                                      |
| [태아 발달] [엄마 몸 변화] [생활 가이드] |
|                                      |
| 태아 발달                            |
| 아기는 몸을 더 활발히 움직이고,       |
| 감각 발달도 조금씩 이어져요.          |
|                                      |
| 엄마 몸 변화                         |
| 배가 조금씩 더 도드라지고, 허리나     |
| 골반에 부담이 느껴질 수 있어요.       |
|                                      |
| 생활 가이드                          |
| [ ] 물을 충분히 마셔요                |
| [ ] 무리하지 않는 산책을 해요          |
| [ ] 불편함이 심하면 진료를 받아봐요    |
|                                      |
+--------------------------------------+
```

섹션 표시 규칙:

- 본문은 긴 문단 하나로 붙이지 않고 짧은 단락으로 나눈다.
- 생활 가이드는 체크 가능한 인터랙션이 아니라 읽기용 체크리스트로 표시한다.
- 사용자 개인 체크 완료 이벤트와 사전 읽기용 체크리스트는 데이터 책임을 분리한다.
- 주의할 점은 있으면 별도 안내 박스로 표시한다.

### 5.4 주차 선택 바텀시트

목적:

1~40주 중 조회할 주차를 빠르게 선택한다.

와이어프레임:

```text
+--------------------------------------+
|                                      |
|        주차를 선택해 주세요           |
|                                      |
|  [현재 주차로 돌아가기]               |
|                                      |
|  1주   2주   3주   4주               |
|  5주   6주   7주   8주               |
|  9주  10주  11주  12주               |
|                                      |
|  18주  현재                          |
|                                      |
|  36주  준비 중                       |
|  37주  준비 중                       |
|                                      |
+--------------------------------------+
```

상태 표시:

- 현재 주차: 강조
- 노출 가능 주차: 기본 활성
- 준비 중 주차: 흐린 상태, 탭 시 준비 중 안내
- 데이터 오류: 전체 오류 배너 표시

### 5.5 준비 중 상태

와이어프레임:

```text
+--------------------------------------+
| <            36주차                   |
+--------------------------------------+
|                                      |
| +----------------------------------+ |
| | 이 주차 정보는 정리 중이에요       | |
| | 준비되는 대로 차분히 읽을 수        | |
| | 있게 보여드릴게요.                 | |
| |                                  | |
| | [ 다른 주차 보기 ]                 | |
| +----------------------------------+ |
|                                      |
+--------------------------------------+
```

문구:

- `이 주차 정보는 정리 중이에요.`
- `준비되는 대로 차분히 읽을 수 있게 보여드릴게요.`

금지:

- `데이터 없음`
- `404`
- `콘텐츠 미발행`
- `paraphrase pending`

## 9. 관리자 화면 명세

### 9.1 주차별 콘텐츠 목록

목적:

운영자가 1~40주 전체 상태를 빠르게 파악하고, 누락 또는 검수 필요 주차를 바로 찾는다.

와이어프레임:

```text
+--------------------------------------------------------------------------------+
| 운영 제어 센터        콘텐츠 > 주차별 아기는요                         세션 종료 |
+----------------------+---------------------------------------------------------+
| 운영 상태             | 주차별 임신백과                                        |
| 계정                  | 40개 주차 중 23개 노출 가능, 17개 정리 필요           |
| 콘텐츠                |                                                         |
|  참조 파일            | [전체] [노출 가능] [검수 필요] [누락 있음] [준비 중]   |
|  지식 콘텐츠          |                                                         |
|  주차별 아기는요      | +-----------------------------------------------------+ |
|  응답 워크플로우      | | 주차 | 상태 | 태아 | 엄마 | 생활 | 질문 | 이미지 | |
| 모니터링              | | 13주 | 가능 | 완료 | 완료 | 완료 | 완료 | 없음   | |
|                       | | 14주 | 가능 | 완료 | 완료 | 완료 | 완료 | 있음   | |
|                       | | 36주 | 누락 | 필요 | 필요 | 필요 | 필요 | 없음   | |
|                       | +-----------------------------------------------------+ |
+----------------------+---------------------------------------------------------+
```

필수 요소:

- 상단 요약 카드
  - 전체 주차 수
  - 노출 가능 주차 수
  - 검수 필요 주차 수
  - 누락 주차 수
- 필터 칩
- 주차 테이블
- 행 클릭 시 주차 상세 오버레이 열기

컬럼:

- 주차
- 발행 상태
- 태아 발달
- 엄마 몸 변화
- 생활 가이드
- 질문/FAQ
- 이미지
- 마지막 수정일

상태 배지:

- `노출 가능`
- `검수 필요`
- `누락 있음`
- `준비 중`
- `보관됨`

### 9.2 주차 상세 오버레이

목적:

한 주차의 모든 콘텐츠를 편집하고 발행 전 검수한다.

와이어프레임:

```text
+--------------------------------------------------------------------------------+
```

- 이미지/크기 메타 영역
- 발행 체크 영역

### 9.3 Paraphrase 검수 패널

목적:

원문과 paraphrase 결과를 나란히 보고 의미 보존과 문체 적합성을 확인한다.

와이어프레임:

```text
+--------------------------------------------------------------------------------+
| Paraphrase 검수                                                    18주차       |
+--------------------------------------------------------------------------------+
| 카테고리: 태아 발달                                                           |
|                                                                                |
| 원문                                                                           |
| +--------------------------------------+                                       |
| | 원문 본문은 관리자에게만 표시됩니다. |                                       |
| +--------------------------------------+                                       |
|                                                                                |
| 사용자 노출본                                                                  |
| +--------------------------------------+                                       |
| | 아기는 몸을 더 활발히 움직이고...    |                                       |
| +--------------------------------------+                                       |
|                                                                                |
| 검수 체크                                                                      |
| [ ] 원문의 의미가 유지됨                                                       |
| [ ] 숫자와 주차 정보가 바뀌지 않음                                             |
| [ ] 산모 대상 문체로 작성됨                                                    |
| [ ] 원문 문장 복사가 없음                                                      |
|                                                                                |
| 상태 [needs_review v]                                                          |
| 검수 메모 [                                                              ]     |
|                                                                                |
| [저장] [ready로 변경]                                                          |
+--------------------------------------------------------------------------------+
```

검수 체크 항목:

- 원문의 의미가 유지됨
- 숫자와 주차 정보가 바뀌지 않음
- 산모 대상 문체로 작성됨
- 원문 문장 복사가 없음
- 의료적 단정 표현이 없음
- 필요한 경우 진료 안내가 포함됨

### 9.4 사용자 앱 미리보기

목적:

관리자가 저장 전 모바일 앱에서 보일 형태를 확인한다.

와이어프레임:

```text
+--------------------------------------+
| 모바일 미리보기                       |
+--------------------------------------+
| 18주차                                |
| 아기는 고구마만큼 자라고 있어요        |
|                                      |
| 태아 발달                             |
| 아기는 몸을 더 활발히 움직이고...      |
|                                      |
| 엄마 몸 변화                          |
| 배가 조금씩 더 도드라지고...           |
|                                      |
| 생활 가이드                           |
| - 물을 충분히 마셔요                   |
| - 무리하지 않는 산책을 해요            |
+--------------------------------------+
```

미리보기 규칙:

- 사용자 앱에 노출되지 않는 원문과 운영 용어는 표시하지 않는다.
- 준비 중인 카테고리는 미리보기에서 `정리 중` 상태로 표시한다.
- 모바일 폭 기준으로 줄바꿈을 확인할 수 있어야 한다.

## 10. 관리자 상태와 액션

### 10.1 상태 전이

```text
pending -> processing -> needs_review -> ready -> archived
                         failed ------^
```

관리자 액션:

- 저장
- 검수 필요로 변경
- ready로 변경
- 보관
- 재처리 요청
- 사용자 앱 미리보기

### 10.2 발행 전 차단 조건

다음 조건 중 하나라도 해당하면 `ready`로 변경할 수 없다.

- 제목 없음
- 주차 요약 없음
- 태아 발달 없음
- 엄마 몸 변화 없음
- 생활 가이드 없음
- 사용자 노출본 본문 없음
- 검수 체크 미완료

MVP에서 자동 차단 구현이 어렵다면, 최소한 경고와 수동 체크리스트를 제공한다.

## 11. 반응형 기준

### 11.1 모바일 앱

- iPhone SE 폭에서도 제목과 버튼 텍스트가 잘리지 않아야 한다.
- 주차 선택은 가로 스크롤 또는 바텀시트 그리드 중 하나를 사용한다.
- 카테고리 탭은 좁은 화면에서 2줄 wrap을 허용한다.
- 긴 본문은 접지 않고 자연스럽게 스크롤한다.

### 11.2 관리자 웹

- 데스크톱 우선이다.
- 1024px 미만에서는 사이드바 접힘 상태를 기본으로 한다.
- 주차 상세는 wide overlay 또는 별도 상세 화면을 사용한다.
- 원문과 사용자 노출본 2열 비교는 좁은 화면에서 상하 배치로 전환한다.

## 12. 접근성 요구사항

### 12.1 사용자 앱

- 모든 주차 선택 버튼은 접근성 라벨을 가진다.
- 준비 중 주차는 disabled 상태와 안내 텍스트를 함께 제공한다.
- 카테고리 이동은 스크린리더에서 순서가 자연스러워야 한다.
- 색상만으로 상태를 구분하지 않는다.
- Dynamic Type에서 본문이 잘리지 않아야 한다.

### 12.2 관리자 웹

- 테이블 필터와 상태 배지는 텍스트 라벨을 포함한다.
- 오버레이는 focus trap을 적용한다.
- 저장, ready 변경 같은 주요 액션은 로딩 상태를 명확히 표시한다.
- 원문과 사용자 노출본 편집 영역에는 명확한 label을 제공한다.

## 14. 구현 메모

### 14.1 앱

- 마이페이지 화면에 `임신백과` 섹션 진입점을 추가한다.
- `PatientContentScreen(section="knowledge")`는 목록형 참고 문서 화면에서 주차별 사전 화면으로 재정의하되, 하단 탭에는 직접 노출하지 않는다.
- 기존 `knowledgePort.listContentItems("knowledge")`는 MVP에서는 유지할 수 있지만, 권장 방향은 `listEncyclopediaWeeks`, `getEncyclopediaWeek` 형태의 포트 분리다.
- 현재 주차는 `pregnancy_profiles.pregnancy_week` 또는 모바일 프로필 API의 주차 값을 사용한다.
- 사용자 앱 API 응답에는 원문 본문을 포함하지 않는다.

### 14.2 관리자

- 기존 `/admin/content/weeks` 흐름을 중심으로 확장한다.
- `AdminWeeksSection`은 주차 목록과 상태 요약을 담당한다.
- `AdminWeekOverlay`는 상세 편집, paraphrase 검수, 앱 미리보기를 담당한다.
- 기존 Day, checklist, question 편집 책임은 유지하되, 사용자 노출본과 원문 연결을 분리해서 보여준다.

## 15. 완료 기준

### 15.1 앱 UI

- 마이페이지의 임신백과 섹션에서 현재 주차 사전으로 진입할 수 있다.
- 사용자는 다른 주차를 선택할 수 있다.
- 최소 세 카테고리 `태아 발달`, `엄마 몸 변화`, `생활 가이드`가 표시된다.
- 준비 중 주차는 따뜻한 빈 상태로 안내된다.
- 사용자 앱에 원문, paraphrase, RAG 같은 운영 용어가 노출되지 않는다.
- 채팅 검색형 UI로 보이지 않는다.

### 15.2 관리자 UI

- 관리자는 1~40주 상태를 목록으로 볼 수 있다.
- 관리자는 원문과 사용자 노출본을 비교할 수 있다.
- 관리자는 paraphrase 본문과 상태를 수정할 수 있다.
- 필수 카테고리 누락 시 발행 경고가 표시된다.
- 사용자 앱 미리보기에서 실제 노출 문구를 확인할 수 있다.
