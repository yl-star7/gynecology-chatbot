# 관리자 운영 매뉴얼

**프로젝트**: 모성간호 AI 상담 챗봇
**버전**: 1.0
**작성일**: 2026-03-30
**대상**: 시스템 운영자/관리자

---

## 1. 로그인

1. 브라우저에서 관리자 콘솔 URL에 접속합니다.
2. 등록된 관리자 전화번호와 비밀번호를 입력합니다.
3. "로그인" 버튼을 누르면 운영 제어 센터로 이동합니다.

> 로그인 시도는 분당 5회로 제한됩니다.

---

## 2. 화면 구성

관리자 콘솔은 왼쪽 사이드바를 통해 4개 섹션으로 구성됩니다.

| 섹션 | 설명 |
|------|------|
| **운영 상태** | 알림 발송, 스케줄, 브랜딩, AI 워크플로우 현황 |
| **계정** | 사용자 관리, 허용 전화번호 관리 |
| **콘텐츠** | 주차별 간호 정보, 문서, 정적 문헌, 응답 워크플로우 |
| **모니터링** | 사용자 활동 로그, 세션 추적 |

---

## 3. 운영 상태

### 3.1 알림 발송

푸시 알림을 전체 사용자에게 즉시 발송합니다.

1. 운영 상태 페이지에서 "알림 발송" 패널을 찾습니다.
2. "알림 보내기" 버튼을 누릅니다.
3. 발송 완료 시 발송 인원수가 표시됩니다.

> 매일 한국 시간 오전 9시에 자동 발송이 설정되어 있습니다.

### 3.2 알림 스케줄 설정

1. "알림 스케줄 설정" 패널에서 원하는 알림 항목을 켜거나 끕니다.
2. 시간을 설정합니다.
3. "스케줄 저장" 버튼으로 저장합니다.

### 3.3 FAB 마스코트 설정

앱에 표시되는 마스코트 이미지와 설문 링크를 관리합니다.

1. "FAB 마스코트" 패널에서 이미지를 업로드합니다 (PNG, JPEG, WebP, GIF).
2. 설문 링크 입력란에 Google Forms 등의 URL을 입력합니다.
3. 저장하면 앱의 마이페이지에서 이 링크가 사용됩니다.

### 3.4 AI 워크플로우 현황

현재 등록된 AI 응답 워크플로우의 상태를 확인합니다.

- **컬렉션**: RAG 벡터 저장소 현황 (이름, 벡터 수, 임베딩 모델)
- **워크플로우**: 등록된 워크플로우 목록 (이름, 상태, 블록 수)
- **테스트**: 발행된 워크플로우에 테스트 질문을 입력하여 응답을 확인할 수 있습니다.

## 4. 계정 관리

### 4.1 사용자 관리

등록된 사용자의 계정 상태를 조회하고 관리합니다.

#### 사용자 조회
1. 왼쪽 패널의 검색창에서 이름이나 전화번호로 검색합니다.
2. 사용자를 선택하면 오른쪽에 상세 정보가 표시됩니다.

#### 전화번호 변경
1. 사용자를 선택합니다.
2. "변경 전화번호"에 새 번호를 입력합니다.
3. "조치 메모"에 변경 사유를 입력합니다.
4. "전화번호 갱신" 버튼을 누릅니다.

#### 세션 초기화
로그인 문제가 있는 사용자의 세션을 강제로 초기화합니다.
1. 사용자를 선택합니다.
2. "세션 초기화" 버튼을 누릅니다.

#### 사용 중단/재개
1. 사용자를 선택합니다.
2. "사용 중단" 또는 "사용 재개" 버튼을 누릅니다.

### 4.2 허용 전화번호 관리

연구 참여자 등 앱 사용이 허용된 전화번호를 관리합니다.

#### 번호 추가
1. 하단 패널에서 전화번호, 표시 이름, 메모를 입력합니다.
2. "허용 번호 추가" 버튼을 누릅니다.

#### 번호 수정/삭제
1. 목록에서 번호를 선택합니다.
2. 수정 후 "선택 번호 수정" 또는 "선택 번호 삭제" 버튼을 누릅니다.

## 5. 콘텐츠 관리

콘텐츠 섹션은 4개 하위 탭으로 구성됩니다.

### 5.1 주차별 간호 정보

임신 1~40주차의 간호 콘텐츠를 관리합니다.

#### 주차 선택 및 편집
1. 왼쪽 목록에서 편집할 주차를 선택합니다.
2. 오른쪽 편집기에서 내용을 수정합니다.

#### 편집 가능 항목
- **제목**: 주차 대표 제목
- **아기 크기**: 비교 대상과 크기 (예: "바나나 16cm")
- **아기 요약**: 아기 발달 요약
- **산모 요약**: 산모 변화 요약
- **히어로 이미지**: 주차 대표 이미지 (업로드)
- **비교 이미지**: 크기 비교 이미지 (업로드)

#### 하위 요소 관리
각 주차에는 다음 하위 요소를 추가/편집/삭제/순서 변경할 수 있습니다:
- **주차 요일**: 요일별 간호 정보
- **섹션**: 콘텐츠 본문 블록
- **에셋**: 미디어 참조
- **미디어**: 파일 업로드

#### 발행
1. 콘텐츠 편집이 완료되면 "발행" 버튼을 누릅니다.
2. 발행된 주차만 사용자 앱에 표시됩니다.

### 5.2 문서 (RAG 자료)

AI 응답에 참조되는 문서를 관리합니다.

#### 문서 등록
1. "새 자료" 버튼을 누릅니다.
2. 제목, 카테고리, 관련 주차, 본문을 입력합니다.
3. 저장하면 AI 응답 시 참조 자료로 활용됩니다.

#### 문서 수정/삭제
1. 목록에서 문서를 선택합니다.
2. 내용을 수정하고 저장하거나, 삭제합니다.

### 5.3 정적 문헌

사용자 앱의 안내 문헌(노트북)을 관리합니다.

#### 문헌 등록
1. "새 안내문" 버튼을 누릅니다.
2. URL 슬러그, 섹션(영양/운동/정신건강 등), 제목, 본문을 입력합니다.
3. 상태를 "발행"으로 변경하면 앱에 표시됩니다.

### 5.4 응답 워크플로우

AI 상담 응답의 동작 규칙을 관리합니다.

#### 워크플로우 조회
1. 목록에서 등록된 워크플로우를 확인합니다.
2. 상태(초안/발행), 트리거, LLM 모델 정보가 표시됩니다.

#### 워크플로우 편집
1. 워크플로우를 선택하면 비주얼 에디터가 열립니다.
2. 이름, 트리거, 검색 범위, LLM 모델을 설정합니다.
3. 노드 기반 편집기에서 응답 흐름을 구성합니다.

#### 테스트
1. 테스트 질문 입력란에 질문을 입력합니다.
2. "테스트" 버튼으로 워크플로우 실행 결과를 확인합니다.

## 6. 모니터링

사용자 활동과 세션을 실시간으로 추적합니다.

### 6.1 활동 로그 (왼쪽 패널)

모든 사용자 활동이 시간순으로 표시됩니다.

- **검색**: 사용자 이름, 활동 내용으로 검색
- **필터**: 활동 유형별 필터 (채팅, 인증, 설정 등)
- **표시 항목**: 시각, 사용자명, 활동 내용, 세션 정보

### 6.2 사용자 세션 (오른쪽 패널)

개별 사용자의 세션 상세를 확인합니다.

1. 사용자 목록에서 대상을 선택합니다.
2. 사용자 정보 (이름, 전화번호, 현재 주차)가 표시됩니다.
3. 해당 사용자의 세션 목록과 최근 활동 내역을 확인할 수 있습니다.

### 6.3 상단 통계

- **실시간 이벤트**: 최근 활동 건수
- **활성 사용자**: 현재 활성 사용자 수
- **세션 수**: 총 세션 수

## 7. 일상 운영 체크리스트

### 매일
- [ ] 오전: 모니터링 페이지에서 전일 활동 확인
- [ ] 오전: 자동 푸시 알림 발송 확인 (오전 9시)
- [ ] 수시: 새 사용자 등록 시 허용 전화번호 추가

### 매주
- [ ] 콘텐츠 > 주차별 간호 정보에서 해당 주차 콘텐츠 확인/발행
- [ ] RAG 문서 최신화 여부 확인
- [ ] 워크플로우 테스트 실행하여 AI 응답 품질 점검

### 필요시
- [ ] 사용자 계정 이슈 처리 (세션 초기화, 전화번호 변경)
- [ ] 마스코트 이미지/설문 링크 업데이트
- [ ] 알림 스케줄 조정

## 8. 문제 해결

| 증상 | 확인 사항 | 조치 |
|------|-----------|------|
| 사용자가 로그인하지 못함 | 허용 전화번호에 등록되어 있는지 확인 | 허용 전화번호 추가 |
| 앱이 응답하지 않음 | 사용자 계정 상태 확인 | 세션 초기화 후 재로그인 안내 |
| AI 응답이 부적절함 | 워크플로우 테스트로 응답 확인 | 워크플로우 규칙 수정, RAG 문서 보강 |
| 푸시 알림이 도착하지 않음 | 모니터링에서 해당 사용자 활동 확인 | 앱 재설치 안내 (푸시 권한 재요청) |
| 콘텐츠가 앱에 표시되지 않음 | 해당 주차/문헌의 발행 상태 확인 | 상태를 "발행"으로 변경 |

---

## 9. 주의 사항

- 관리자 비밀번호는 주기적으로 변경해 주세요.
- 허용 전화번호 삭제 시 해당 사용자는 더 이상 앱에 로그인할 수 없습니다.
- RAG 문서 삭제 시 해당 내용이 AI 응답에서 참조되지 않습니다.
- 워크플로우 변경 후에는 반드시 테스트를 실행하여 응답 품질을 확인해 주세요.
- 사용자의 개인정보(전화번호)는 암호화되어 저장됩니다.
