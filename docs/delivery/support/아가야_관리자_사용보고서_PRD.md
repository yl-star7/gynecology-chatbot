# 아가야 관리자 사용 보고서 PRD

**문서 목적**: 첨부 앱 화면의 빨간 코멘트가 가리킨 영역을 관리자에서 어디서 수정하거나 노출 제어할 수 있어야 하는지 정의한다.
**문서 성격**: 완료보고서가 아니라 `관리자 사용 보고서 + 수정 기능 PRD`다. 단순 현황 매칭이 아니라, 관리자에서 수정 가능해야 할 항목과 추가 개발이 필요한 항목을 함께 정리한다.
**작성일**: 2026년 5월 12일

---

## 1. 핵심 정정

유저가 준 이미지의 뜻은 “앱 화면 설명”이 아니라 “빨간 표시된 영역을 관리자에서 각각 수정할 수 있게 해야 하지 않느냐”이다.

따라서 이 문서는 아래 관점으로 다시 정리한다.

- 앱에서 보이는 문구/버튼/이미지/노출 상태는 운영자가 관리자에서 수정할 수 있어야 한다.
- 현재 관리자 메뉴가 있으면 정확한 위치를 적는다.
- 현재 관리자 메뉴가 없으면 “수정 불가”로 끝내지 말고, 어느 관리자 화면에 기능을 추가해야 하는지 적는다.
- `15주 2일`, `임신 107일째`, `만나기까지 173일` 같은 값은 콘텐츠 문구가 아니라 사용자 상태값이지만, 잘못 표시될 수 있으므로 운영 보정 화면이 필요하다.

## 4. 추가 개발이 필요한 관리자 화면

### 4.1 사용자 상태값 보정 화면

필요 이유:
- `15주 2일`, `임신 107일째`, `만나기까지 173일`은 콘텐츠가 아니라 사용자별 계산값이다.
- 하지만 운영 중 잘못 표시되면 관리자에서 바로 보정해야 한다.

위치 제안:
- 계정 > 사용자 관리 > 사용자 상세
- 또는 채팅 로그 > 유저 상세 > 프로필 보정

필드:
- 출산예정일
- 임신 주차/일차 override
- 보정 사유 메모
- 보정 이력

앱 반영:
- 홈 주차/일수
- 오늘,우리 일별 콘텐츠 선택
- 대화 중 주차 정보

### 4.2 앱 UI 문구 관리 화면

필요 이유:
- 현재 일부 섹션명/탭명/placeholder가 앱 고정 문구일 수 있다.
- 이미지 코멘트 의도상 운영자가 바꾸고 싶어 하는 문구는 “수정 불가”가 아니라 관리자화 후보로 분류해야 한다.

위치 제안:
- 자산 관리 > 공통 풀 > 앱 UI 문구
- 또는 시스템 운영 > 브랜딩 > 앱 문구

대상 후보:
- `아기와 엄마`, `체크리스트`, `아기와 대화`
- `오늘 아기는요`, `오늘 엄마는요`, `오늘의 체크리스트`
- `임신백과` 카드 설명 문구
- `사용설명서`, `사용설명서 보기`
- 채팅 입력창 안내문

### 4.3 대화 플로우 편집/미리보기 화면

필요 이유:
- Image #8은 `기분 -> 질문 -> 자유대화` flow 페이지를 어디서 수정하는지 묻고 있다.
- 운영자는 YAML이나 내부 이름이 아니라 앱 화면 흐름 기준으로 수정해야 한다.

위치:
- 대화 엔진 > 워크플로우
- 대화 엔진 > 기분별 변주

필요 기능:
- 기분 질문 수정
- 기분 버튼 목록 수정
- 기분 선택 후 공감 문장 수정
- 주차 정보 제안 문구/버튼 수정
- 태교 질문 연결 확인
- 자유대화 전환 규칙 확인
- 앱 화면 미리보기

## 6. 수용 기준

- 빨간 코멘트가 달린 앱 화면 요소별로 관리자 수정 위치가 있어야 한다.
- 현재 수정 위치가 없으면 추가해야 할 관리자 화면과 필드를 명시해야 한다.
- `15주 2일` 같은 사용자 상태값은 콘텐츠로 오해하지 않되, 운영 보정 기능이 필요하다고 명시해야 한다.
- 설문은 버튼별 보이기/가림 처리와 링크 수정이 가능해야 한다.
- 대화는 `기분 -> 질문 -> 자유대화` 흐름을 관리자에서 단계별로 수정/확인할 수 있어야 한다.
- 교수님/운영자에게 전달해도 개발자 용어 없이 이해 가능한 문장이어야 한다.

## 7. 운영자 수정 요청 양식

| 항목 | 작성 예시 |
| --- | --- |
| 앱 화면 | 오늘,우리 > 아기와 엄마 |
| 수정 대상 | 오늘 엄마는요 본문 |
| 현재 문구 | 피부 가려움이 생길 수 있어요... |
| 변경 문구 | 피부가 건조하거나 가려울 수 있어요... |
| 관리자 위치 | 자산 관리 > 주차별 > 15주차 > 일별 본문 > 2일차 |
| 현재 관리자 기능 | 있음 |
| 추가 개발 필요 여부 | 없음 |

추가 개발이 필요한 경우:

| 항목 | 작성 예시 |
| --- | --- |
| 앱 화면 | 홈 |
| 수정 대상 | `15주 2일` 표시 |
| 현재 상태 | 사용자 상태값 자동 계산 |
| 필요한 기능 | 관리자에서 출산예정일/주차 기준값 보정 |
| 추가될 위치 | 계정 > 사용자 관리 > 사용자 상세 |
