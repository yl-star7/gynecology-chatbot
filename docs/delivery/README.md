# 아가야 납품 문서 안내

이 폴더의 최종 제출 문서는 아래 3개입니다.

| 구분 | 파일 | 용도 |
| --- | --- | --- |
| 앱 완료보고서 | `아가야_앱_완료보고서.docx` | 교수님이 앱 화면 기준으로 기능 완료 여부를 검수하는 문서 |
| 관리자 완료보고서 | `아가야_관리자_완료보고서.docx` | 교수님이 관리자 화면 기준으로 운영 기능을 검수하는 문서 |
| 보안정보 전달문서 | `아가야_보안정보_전달문서.docx` | 관리자 계정, 테스트 계정, 접속 주소, 지원 연락처를 별도로 전달하는 문서 |

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `support/` | 내부 인수인계용 Markdown 문서입니다. 기술 명세, 운영 매뉴얼, 재현 절차, 검수 체크리스트가 있습니다. |
| `evidence/screenshots/` | 예전 완료보고서와 지원 문서에서 쓰던 화면 증빙 이미지입니다. |

## 전달 순서

1. 교수님께 `아가야_앱_완료보고서.docx`와 `아가야_관리자_완료보고서.docx`를 먼저 전달합니다.
2. 관리자 접속 정보가 필요한 담당자에게만 `아가야_보안정보_전달문서.docx`를 별도로 전달합니다.
3. 기술 담당자가 추가 확인을 요청하면 `support/` 문서를 공유합니다.

## 보안 주의

`아가야_보안정보_전달문서.docx`에는 관리자 계정과 임시 비밀번호가 들어갑니다. 완료보고서와 같이 공개 공유 폴더에 오래 보관하지 말고, 전달 후 비밀번호 변경을 안내합니다.
