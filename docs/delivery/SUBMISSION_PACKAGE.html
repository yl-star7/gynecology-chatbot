3. 검수 재현 스크립트

3.1 사전 준비

  • 검수용 사용자 1개 이상(전화번호 인증 가능 계정)
  • 검수용 관리자 계정 1개
  • API 호출 도구(curl, Postman 등)
  • 증빙 저장 폴더(스크린샷, 요청/응답 로그, 실행 시각 기록)

3.2 화면/라우트 기준

구분대상
관리자 화면/admin/login, /admin/operations, /admin/accounts, /admin/content/weeks, /admin/content/documents, /admin/content/static, /admin/content/policies, /admin/monitoring
모바일 APIPOST /api/mobile/auth/start-phone-verification, POST /api/mobile/auth/login, GET /api/mobile/auth/session, POST /api/mobile/chat, GET/PATCH /api/mobile/today, GET /api/mobile/sessions, GET /api/mobile/sessions/[sessionId]
관리자 APIPOST /api/admin/push/send

3.3 AC별 재현 시나리오

AC 사전 준비 시나리오 기대 결과 증빙
AC-001 검수 사용자 전화번호, OTP 수신 가능 상태 OTP 요청 → OTP 로그인 → 세션 조회 → 비인증 상태에서 관리자 보호 라우트 접근 인증 성공, 세션 조회 200, 관리자 비인가 접근 차단 API 요청/응답 캡처, 관리자 로그인 리다이렉트 화면
AC-002 유효 모바일 세션 POST /api/mobile/chat 로 일반 질문 전송 200 응답, assistant 응답 반환, 실패 시 에러 구조 유지 요청/응답 JSON, 응답 시각 및 sessionId 기록
AC-003 인증 완료 세션 금칙/위험 입력 전송 후 안전 분기 동작 확인 차단 또는 안전 고지 응답 반환 금칙 입력별 요청/응답 로그, 안전 고지 캡처
AC-004 관리자 로그인 가능 상태 운영 상태, 사용자 설정, 모니터링 화면 진입 및 사이드바 이동 확인 각 화면 제목/섹션 정상 렌더링 페이지 URL+화면 제목 캡처, 네비게이션 이동 전후 캡처
AC-005 관리자 로그인 상태 주차별 간호 정보, 문서, 정적 문헌, 응답 워크플로우 화면 접근 각 콘텐츠 관리 화면 접근/조회 가능 4개 콘텐츠 화면 제목 캡처
AC-006 채팅 전송 완료, 유효 sessionId 세션 목록 조회 → 세션 상세 조회 세션 존재, 메시지 재조회 가능 세션 목록/상세 응답 JSON, sessionId 일치 로그
AC-007 운영 배포 접근 권한, 운영 점검 시간 확정 운영 URL에서 인증 → 채팅 → 세션 재조회, 관리자 주요 화면 접근 순차 실행 운영 URL에서 핵심 기능 실제 실행 가능 운영 URL 접속 캡처, 실환경 요청/응답 로그, 점검 일시/점검자 기록

3.4 운영 환경 전용 확인 항목

  • 운영 URL 실가동 및 SSL 상태
  • 스토어 제출 및 배포 결과(TestFlight, Play Console)
  • 외부 계정 연동 항목: OTP/SMS 발송(Twilio), 푸시 발송 인프라(Expo/FCM/APNs)
  • 관리자 수동 푸시 발송 API는 관리자 세션 인증 상태에서 확인
