# Docs Index

현재 상단에서 바로 보는 문서는 아래 2개입니다.

- `active/CONTRACT.html`: 서명용 단일 계약서
- `reference/`: 현재 제품/구조 기준 문서

나머지 문서는 성격별로 분리했습니다.

## `active/`

지금 바로 열어보는 현재 문서입니다.

- `CONTRACT.html`

## `reference/`

제품/설계 참고 문서입니다.

- `PRD.md`
- `IMPLEMENTATION_PLAN.md`
- `UI_SPECS.md`
- `DATABASE_SCHEMA.md`
- `DEVELOPMENT.md`

## `archive/`

이전 계약 부속서, 잠금본, 견적서, 문서 원본 보관본입니다.

- 이전 SOW/PRD 기준서
- 이전 검수 체크리스트
- 이전 견적서
- DOCX/HWP/HWPX/PDF 원본
- 과거 설명 문서 `SYSTEM_DOCUMENTATION.md`

## `tools/`

문서 생성용 스크립트와 템플릿입니다.

- `generate-contract.mjs`
- `generate-prd-baseline-pdf.py`
- `generate-sow.mjs`
- `blank.hwpx`
