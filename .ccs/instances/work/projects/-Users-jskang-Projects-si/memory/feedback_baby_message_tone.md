임신 주차별 baby_message는 아기의 1인칭 말투("엄마, 내 심장이...") 금지.
3인칭 관찰자 시점("아가는 심장이 콩닥거리기 시작했어요.")으로 작성.

**Why:** 유산된 경우, 아기가 직접 말하는 형태의 메시지가 사용자에게 큰 상처가 될 수 있음.

**How to apply:** baby_message, babyBody 등 아기 발달 정보를 작성하거나 수정할 때 항상 3인칭("아가는", "아가의") 사용. "엄마," 호칭, 이모지(👶), "아기의 말:" 프레임도 제거.
